# CHGS ТСД — загрузка приложения

Приложение «CHGS ТСД» для складских терминалов сбора данных (Android 7.0 и новее): вход сотрудника по QR-пропуску и PIN, приёмка, распределение по местам хранения, печать этикеток через Print Agent.

## Скачать

Последняя версия — на странице [Releases](https://github.com/chgs-pro/pdt-download/releases). Файл `chgs-pdt-<версия>.apk`, контрольные суммы — в `SHA256SUMS.txt`.

## Установка

**С ТСД.** Откройте ссылку на APK в браузере ТСД, скачайте файл и откройте его. Android один раз попросит разрешить установку из этого источника.

**Через компьютер (USB).** Включите на ТСД отладку по USB и выполните:

```
adb install -r chgs-pdt-<версия>.apk
```

Если подключено несколько устройств, укажите серийный номер: `adb -s <serial> install -r …`.

После первой установки устройство привязывают к площадке: администратор создаёт запись ТСД в диспетчере WMS и выдаёт одноразовый QR-код привязки, его сканируют на экране подключения приложения.

## Обновление

Новая версия ставится поверх прежней тем же способом: привязка устройства и настройки сохраняются. Все версии подписаны одним ключом; APK с другой подписью Android поверх не установит.

Подпись: сертификат `CN=CHGS PDT, O=CHGS, C=RU`, SHA-256 `95a46a21471ff2e0e515cff6fdaeb074e0545dae74dc7051f17ede7952dda9fb`. Проверить: `apksigner verify --print-certs chgs-pdt-<версия>.apk`.
